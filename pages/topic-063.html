The city story for Practice case studies follows Brightloaf through a problem, solution, stress event, and explicit limit.

Cloud City mapping table

City conceptReal GCP termBoundary to remember

4 Practice Exercise

LIVE DEMO SAFETY: T2 by default. Set DEMO_PROJECT_ID, confirm the active project, use a budget alert, and do not run apply until the plan is reviewed.

PREREQUISITES

gcloud config list
gcloud projects describe "$GOOGLE_CLOUD_PROJECT"
gcloud services list --enabled
: "Guard: DEMO_PROJECT_ID must be set"
test "$GOOGLE_CLOUD_PROJECT" = "$DEMO_PROJECT_ID"

PATH EQUIVALENCE TABLE

ActionGUITerraformCLI
Inspect/create the resourceCloud Console product page; confirm project and regionReview module, validate, and planUse the narrow gcloud/kubectl/bq command

GUI PATH

Open the relevant Cloud Console product for Practice case studies, select the guarded project, use the smallest safe setting, and capture status and audit evidence.

TERRAFORM PATH

terraform init
terraform fmt -check
terraform validate
terraform plan -var="project_id=$DEMO_PROJECT_ID"
# apply only after review and explicit opt-in
terraform apply -var="project_id=$DEMO_PROJECT_ID" -var="allow_apply=true"
terraform output
terraform destroy -var="project_id=$DEMO_PROJECT_ID"

Do not commit Practice case studies state or secrets; use remote locking and team ownership.

CLI PATH

gcloud config list
gcloud projects describe "$DEMO_PROJECT_ID"
gcloud services list --enabled --project="$DEMO_PROJECT_ID"

OBSERVE

Check Practice case studies status, audit logs, health metrics, and matching D1/D2 nodes.

EXPECTED RESULT

The intended Practice case studies boundary is visible and the result is attributable to the guarded project.

BREAK IT ON PURPOSE

In a disposable project for Practice case studies, revoke a narrow role, block a health check, or select an exhausted range. Observe, diagnose, and restore it.

TROUBLESHOOTING

Check project, API enablement, IAM, quota, DNS, firewall, logs, and eventual consistency for Practice case studies.

CLEANUP

Destroy named Practice case studies resources, then verify deletion and billing asynchronously.

COST / SAFETY NOTE

Tier T2 for Practice case studies: use free-tier or cents-scale resources where available; verify current pricing and delete promptly. T4 topics are plan-only by default.
