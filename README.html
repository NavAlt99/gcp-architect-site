Setup and safety

Build the static learning site from the roadmap source, then browse without credentials.

Build

python3 scripts/build_site.py --roadmap ../gcp-architect-roadmap.md

The build writes a manifest and runs content/link/diagram checks.

Live-demo guardrails

Use a disposable project, confirm the active project and region, set a budget alert, keep permissions narrow, review Terraform plans, and clean up named resources. Browsing is free; create/apply operations can incur charges.

export DEMO_PROJECT_ID="your-disposable-project"
gcloud config get-value project
gcloud projects describe "$DEMO_PROJECT_ID"
terraform plan -var="project_id=$DEMO_PROJECT_ID"
# apply only after review and explicit opt-in

Evidence

Use Cloud Console, CLI, Terraform, logs, metrics, audit logs, quotas, and current official product documentation as mutually checking evidence. Never commit state files, credentials, tokens, or customer data.
